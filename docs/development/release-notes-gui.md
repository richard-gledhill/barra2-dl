## Notebook GUI

barra2-dl now has a notebook GUI. Install `barra2-dl[gui]` and run `barra2-dl-gui` to place masts and draw an area on a
map, see and choose the BARRA2 grid nodes, run the downloads, and read a summary of each run. It runs the same engine as
a project file, which is now documented key by key. See the
[GUI guide](https://richard-gledhill.github.io/barra2-dl/gui/) and the
[project-file reference](https://richard-gledhill.github.io/barra2-dl/project-file/).

The GUI was raised by [atl3b](https://github.com/atl3b) in
[issue #59](https://github.com/richard-gledhill/barra2-dl/issues/59). Thank you.
